# RentSight brand assets

- `rentsight-mark.svg` is the primary RentSight mark. Use it in the extension UI, store listing, checkout, and other placements where the magnifying-glass detail has room to read.
- `rentsight-toolbar.svg` is the optical-size variant for Chrome's small toolbar placement. It keeps the same house, badge shape, and palette while omitting the magnifying glass entirely for maximum clarity.
- `icon-16.png` and `icon-32.png` are exports of the toolbar variant.
- `icon-48.png`, `icon-128.png`, and `icon-source.png` are exports of the primary mark.

Palette: evergreen `#05472a`, sage `#d9e8d2`, and ivory `#f5f1df`.
